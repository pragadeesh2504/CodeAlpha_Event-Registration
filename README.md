# 🎟️ Event Registration System

A simple web-based application to manage event sign-ups, participant details, and confirmations. Built as part of the CodeAlpha internship.

## 🚀 Features
- User-friendly registration form
- Event details page with date, time, and venue
- Participant list management (view, edit, delete)
- Confirmation messages for successful registration
- Admin dashboard to monitor registrations

## 🛠 Tech Stack
- **Frontend:** HTML, CSS, JavaScript (or React if used)
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Version Control:** Git & GitHub
